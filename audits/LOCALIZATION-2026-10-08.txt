Architecture audit
  Vanilla TypeScript HTML renderers in apps/client/src/ui plus main.ts.
  No existing localization system. UI.shell and UI.text render presentation;
  several HUD components update on frames. Settings use platform/storage.ts.
  MenuNavigation already supports select controls via controller left/right/A.
  Browser and Electron use the same Vite bundle and local storage abstraction.
  Shared character, stage and tournament definitions also supply visible text.
  Localize at presentation boundaries; do not modify shared definitions, IDs,
  network messages, simulation hashes, input bitmasks or saved control schemas.

Risks / checks
  Never call navigation functions on locale change when they reset matches,
    disconnect rooms, change music or clear pending gameplay state.
  Re-rendered settings must preserve scroll/focus and replace old dialogs.
  Update underlying pause/HUD/result text without changing simulation.
  Escape user-provided interpolations at HTML boundaries.
  Avoid new per-frame formatting allocations; cache number formatters.
  No language-specific assets downloaded, no dependency additions.
  Physical controllers and Windows need explicit manual verification when
    unavailable here; do not infer those results from browser builds.
