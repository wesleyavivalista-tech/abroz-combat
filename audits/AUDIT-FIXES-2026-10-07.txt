AUDIT FIXES — 2026-10-07

Resolved all six findings from GAME-AUDIT-2026-10-07.txt.

H1: Zombie claw contact now checks the existing six-frame active interval.
Each struck seat is recorded in the fighter's snapshot-owned hitTargets list,
reset at the next claw start. Misses do not consume the window, and a target
cannot take repeated damage during one swing. Existing 36-frame pose end,
84-frame attack cadence, damage, poison, movement and hitstop behavior remain.

M1: Fifth-hit escape is immediately bounded by the actual arena width, including
periodic, returning-projectile, Jopa, Nikalz, structure and direct-hit paths.
Horizontal escape stops at solid house/wall surfaces; friendly walls and
one-way platform tops preserve their existing behavior. Unobstructed escape
still travels 40 units. No wait for a later movement tick or hitstop expiry.

M2: Grave rollback explicitly hides a previously created zombie and its shadow.
Grave/fighter lighting visitors use the current phase, rather than whether a
zombie renderer was once allocated. A reused ID with a different character
recreates the visual and disposes the old instance without disposing shared art.

M3: Extracted the existing KO status cleanup into clearFighterCombat, reused by
shared round/result/forfeit cleanup. Moves, ability deadlines, modes, mounts,
grapples, velocities and input buffers end consistently. Health, lives, meter,
spent supers, competition scores and next-round configuration are preserved.
Removed the redundant normal-result cleanup list. No tournament scoring changes.

M4: Authoritative zombie shamble uses the existing deterministicSin helper.
The 0.49 movement multiplier and rounding remain unchanged. Added explicit
cross-engine undead scenarios covering all four arenas, slow modifiers and
snapshot restoration; the existing native-sine movement comparison also passes.

L1: The eight-player cross-engine scenario uses non-training simulation with
controlled result resets. It asserts that both Jomp's requested ultimate and
Roms's requested special actually start, instead of comparing idle dummy traces.
