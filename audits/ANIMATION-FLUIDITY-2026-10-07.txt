CAUSES REMAINING AFTER EARLIER WORK
1. SceneRenderer supplied stateFrame-based time to continuous cosmetic effects. Changing action resets stateFrame, restarting breathing/shimmer/aura phase; Fausto's accumulated aura clock could also stall when its input time jumped backwards.
2. Dash entry/exit was excluded from otherwise safe neutral locomotion interpolation, creating a one-tick root discontinuity.
3. Drupa's rolling rotation and Buda aura sampled whole state ticks even when fractional presentation time was available.
4. Limited authored pose counts remain a real constraint. Raising playback FPS cannot add useful poses and would rush existing holds.

IMPLEMENTATION
- RenderInterpolation now maintains a continuous cosmetic clock, advanced only after a successful live fixed simulation step. State changes do not reset it. Pause, hitstop, stalled network ticks and snapshot replacement do not advance it. Cosmetic time never enters saved/authoritative state. The clock uses fractional display time between successful ticks and is constant-cost.
- main.ts commits that clock immediately after a successful step and supplies it separately to SceneRenderer. Existing simulation/input/network control flow remains unchanged.
- SceneRenderer supplies continuous cosmetic time to all fighter and ordinary clone visuals. Render adapters retain authoritative simulationFrame forwarding.
- Neutral DashForward/DashBackward entry/exit join the existing safe locomotion transitions. Poses switch immediately; root motion interpolates between adjacent positions. Damage, health/life changes, facing changes, attached actors, respawns, mode changes, teleports and attacks remain protected by the existing exclusions. Landing remains exact.
- Drupa rolling uses the existing fractional state clock; Buda aura uses the continuous cosmetic clock. No scale constants, artwork dimensions or beam collision geometry changed.
- Dodo's drawn performance sequence explicitly retains its state-relative clock. Continuous effect time must not change the opening frame of an authored sequence.
- Updated the existing animation-review page to exercise the same clock as the game.
