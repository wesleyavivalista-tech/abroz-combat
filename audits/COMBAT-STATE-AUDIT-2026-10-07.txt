STATE BUGS FOUND

1. MEDIUM — Stale daze flag after airborne house-collapse recovery.
Location: packages/game-core/simulation/GameSimulation.ts, landing into Knockdown.
Reproduction: build Luizinho's house around an airborne opponent, destroy it while
that opponent is inside, then let the opponent land and recover. The opponent has
zero stun and is Idle, but dazed remains true. A subsequent Nikalz forehead dive
incorrectly treats the recovered opponent as already stunned and skips its stun.
Confirmed in a failing regression before the fix.

2. HIGH — Gym Bro's deferred landing stun can survive its original flight.
Location: the same landing branch, gymLandingStun cleanup.
Reproduction: Jomp completes Gym Bro's throw; five follow-up contacts trigger the
existing combo escape before the target lands. The target lands in Fall/Land and
recovers, but retains gymLandingStun. An unrelated later airborne hit can consume
that obsolete flag and impose Gym Bro's landing stun.
Confirmed in a failing regression before the fix.

No additional crash, permanent control lock, or multiplayer divergence was confirmed
by this audit. This is bounded test evidence, not proof that every possible pair of
abilities and every input sequence is bug-free.

ROOT CAUSES
1. Landing already ended ordinary airborne hitstun by setting stun=0, but did not
   clear the associated dazed flag. Forehead-dive protection reads that flag even
   after the fighter resumes normal movement.
2. Landing consumed gymLandingStun only in the AirHitStun path. Combo escape changes
   the state to Fall, bypassing consumption and leaving the deferred effect stale.

FIXES IMPLEMENTED
- Clear dazed alongside the existing stun=0 transition into Knockdown.
- Clear any remaining gymLandingStun after landing finishes. The normal Gym Bro
  landing branch still applies its original stun first. This also leaves the
  existing combo-escape behavior unchanged while preventing a later stale trigger.
- Regenerate the deterministic simulation revision used for peer compatibility.

Regression risk: low, localized to landing cleanup. Existing normal Gym Bro landing
stun, Nikalz's stun through landing, grounded house collapse, knockdown protection,
combo escape, movement, and timed-mode tests pass. No damage, cooldown, movement,
animation duration, attack timing, or ability duration was edited.

Remaining technical risks, not confirmed bugs:
- Several states are represented by a state name plus flags/deadlines/references.
  Adding a fighter still requires checking shared cleanup and specialized overrides.
- Early returns for meteor, riders, grabs, traps and armored actions make ordering
  important. A new overlapping effect must explicitly define which system owns
  control; a generic 'stunned means everything cancels' rule would break intended armor.
- Several effects intentionally outlive an interrupted animation (projectiles,
  summons, modes). They must not be removed just because their casting move ends.
- Hitstop freezes some movement/animation clocks while absolute ability deadlines
  continue. Existing rules were preserved; no timer architecture was replaced.
- The intended priority of pre-existing loan locks while riding Jopa's invulnerable
  mount deserves design confirmation before changing either behavior. The current
  mount control override was left unchanged; no new rule was invented.
- Grounded collapse has an authored seven-second stun while airborne ordinary
  hitstun ends on landing. That existing duration distinction was preserved rather
  than changing balance under the label of cleanup.
