PRE-LAUNCH AUDIO AND MUSIC AUDIT — 2026-10-08

AUDIO BUGS FOUND
1. Fading-source cleanup lost ownership (medium).
   AudioManager.stopVoice removed sources from its voices map immediately, then
   deferred stop/disconnection by 24ms. dispose cancelled the deferred timer, so
   stopEffects could no longer explicitly stop or disconnect those sources.
   Closing the context still silenced playback, but cleanup was incomplete and
   pause/reset could not immediately flush these fading tails.
   Reproduction: start an ability loop, reconcile it away, dispose before 24ms.
   Fix: retain retiring voices separately until disconnected; stopEffects flushes
   both sets and removes stale ability-loop handles. Diagnostics show retiring
   sources separately from admitted voices. Regression risk: low; fade timings
   and admission limits remain unchanged.

2. Interrupted AudioContext did not resume (medium).
   unlock handled suspended only, despite other non-running states such as an
   interrupted context. Reproduction: context enters interrupted, user interacts.
   Fix: attempt resume for any non-running, non-closed context, preserving the
   existing pending-resume guard. Fake interrupted-state reproduction passed;
   real hardware interruption recovery still needs Safari/device testing.

MUSIC SYSTEM PROBLEMS
3. Autoplay denial permanently disqualified valid music (high).
   HTMLMediaElement.play NotAllowedError used the same failure path as a corrupt
   file. This could blacklist menu music and all fallback tracks for the session.
   Reproduction: deny initial media playback, then allow it and unlock again.
   Fix: remove denied playback, retain track eligibility and retry on unlock.
   Gate repeated state updates while waiting, preventing per-frame retry churn.
   Genuine media errors retain the existing fallback behavior.

No missing registered sound paths found: 1,146 definitions reference 491 distinct
files (8,143,220 stored bytes). Supplied menu, four arena and victory track hashes
pass existing tests. Menu/selection share one track. Existing authored final,
championship, party and defeat selection rules were preserved. Arena ambience
with no authored URL intentionally stays silent; this is not a broken path.

BROWSER-SPECIFIC RISKS
- Browser gesture policies vary, especially for gamepad-only startup. Recovery
  works on the next accepted unlock; a browser may still require a click/key.
- Real Safari interruption, OS sleep and output-device changes remain untested.
- Speech synthesis for the optional DEAD cue depends on an installed local voice;
  recorded 3/2/1/Fight clips remain separate and unchanged.
- First-use material samples are asynchronously preloaded. Before decoding finishes,
  an asset-only cue can be omitted rather than delayed; cold/slow-storage listening
  should verify this is acceptable. Missing-file playback remains nonfatal.
- MP3 loop seams, Bluetooth latency and actual speakers cannot be certified by
  offline peak measurements.
