Install the web app

An app window with the Abroz Combat icon. Internet and a keyboard or controller required. Touch controls are not available.

  • Chrome / Edge: use the install icon in the address bar or Install app in the browser menu.
  • Safari on Mac: File → Add to Dock.
  • iPhone / iPad: Safari → Share → Add to Home Screen.

Desktop beta downloads

Unsigned test builds. Windows and macOS may warn or block installation. Online matches require internet.
